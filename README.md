# Slide Factory

**An agent-native design system for professional, editable presentations.**

Slide Factory is an open-source project for creating structured, visually consistent, and editable presentation slides with AI coding agents such as Codex and Claude Code.

It combines reusable slide patterns with user-provided master templates to produce presentations adapted to their content, audience, and purpose.

## Concept

**Design once. Adapt to any master. Build natively.**

Slide Factory is guided by four principles:

1. **Master-driven design** — Respect the visual identity, typography, colors, and layout conventions of a specified presentation template.
2. **Reusable slide patterns** — Curate and reuse slide structures, including consulting-style layouts, diagrams, and information hierarchies.
3. **Native editability** — Prefer editable presentation objects over flattened images for text, tables, charts, and diagrams.
4. **Communication-first design** — Optimize logical structure, information density, visual hierarchy, and audience comprehension.

## Intended Capabilities

- **Master templates:** Analyze user-provided templates and apply their design conventions.
- **Slide pattern library:** Collect, classify, and search reference layouts, such as comparison matrices, architecture diagrams, process flows, and executive summaries.
- **Adaptive generation:** Select and adapt patterns to the source content and target master instead of copying reference slides.
- **Quality assurance:** Check visual consistency, readability, content fidelity, and editability.

## Design Goals

- Produce professional, consulting-quality presentations.
- Support information-dense Japanese and English slides.
- Preserve editable text, shapes, tables, and diagrams wherever practical.
- Separate content structure from visual styling.
- Make slide generation reproducible across coding agents.
- Respect licensing and attribution requirements for reference materials.

## Project Status

**Concept / initial development.**

The implementation architecture, supported tools, and skill interface are not yet finalized. The initial target is a reusable skill for Codex and Claude Code, with PPTX as the primary output format.
